# 감정 기록 앱 (Emotion Tracking App)

감정을 시간, 장소, 신체와 함께 기록하고 다차원으로 시각화하는 웹 애플리케이션입니다.

## 기능

### Phase 1 MVP (완료)
- ✅ 감정 기록 기능 (복수 감정 선택, 강도 설정)
- ✅ 신체 감각 기록 (2D 신체 맵)
- ✅ 시간 및 장소 기록
- ✅ 로컬 스토리지 데이터 저장
- ✅ 기록 목록 뷰 (수정/삭제)
- ✅ 사인파 시각화 (하루/주/월/년 스케일)

### Phase 2 시각화 (완료)
- ✅ 장소 카테고리별 시각화 (막대 그래프)
- ✅ 2D 신체 히트맵 (색상/크기 기반)
- ✅ 사용자 정의 카테고리 입력
- ✅ 숨은 키워드 시스템 (의식 탐구 도구 활성화)
- ✅ 시각화 탭 분리 (시간/장소/신체)
- ✅ 인터랙티브 툴팁 및 호버 효과

### Phase 3 고급 기능 (완료)
- ✅ 기록 필터링 (감정/장소/신체/날짜별)
- ✅ 전체 텍스트 검색
- ✅ 필터 초기화 및 결과 카운터
- ✅ 데이터 내보내기 (JSON/CSV)
- ✅ 사용자 정의 카테고리 표시

### 향후 개선 방향 (Phase 4-5)
- 🔮 GPS 연동 및 지도 시각화 (Leaflet/Mapbox)
- 🔮 3D 신체 모델 (Three.js)
- 🔮 고급 의식 레이어:
  - 말나식 모드 (시공간 통합 시각화)
  - 공(空) 레이어 (비실재성 시각화)
  - 성의 개입 레이어 (빛과 파티클 시스템)

## 주요 특징

### 🎯 다차원 기록
- **감정**: 복수 감정 선택 가능, 각 감정의 강도(1-10) 설정
- **신체**: 2D 신체 맵에서 클릭하여 감각 위치 표시
- **시간**: 수정 가능한 타임스탬프
- **장소**: 카테고리 선택 또는 직접 입력
- **사용자 정의**: 자유로운 카테고리 추가

### 📊 3가지 시각화 모드
1. **시간 시각화**: 사인파로 표현된 시간의 순환 (하루/주/월/년)
2. **장소 시각화**: 장소별 감정 빈도 막대 그래프
3. **신체 시각화**: 부위별 감각 빈도 히트맵

### 🔍 강력한 필터링
- 감정, 장소, 신체 부위별 필터
- 날짜 범위 선택
- 전체 텍스트 검색
- 실시간 결과 카운터

### 💾 데이터 관리
- 로컬 스토리지 자동 저장
- JSON/CSV 형식 내보내기
- 기록 수정 및 삭제

### ✨ 숨은 기능
특정 키워드(말나, 알아차림, 공, 성 등)를 사용자 정의 카테고리에 입력하면 확장 모드가 활성화됩니다.

## 사용 방법

1. `index.html` 파일을 브라우저에서 열기
2. "기록하기" 탭에서 감정 기록
3. "기록 목록"에서 저장된 기록 확인 및 필터링
4. "시각화"에서 시간/장소/신체별 패턴 분석
5. 헤더의 내보내기 버튼으로 데이터 백업

## 기술 스택

- React 18 (CDN)
- D3.js v7 (데이터 시각화)
- LocalStorage (데이터 저장)
- Vanilla CSS (스타일링)

## 핵심 개념

이 앱은 두 가지 방식으로 사용할 수 있습니다:

1. **일반 사용자**: 감정 패턴을 추적하고 자기 이해를 증진
2. **수행자**: 특정 키워드 사용 시 의식 탐구 도구로 확장

숨은 기능은 사용자가 자연스럽게 발견하도록 설계되었습니다.

## 프로젝트 통계

- **총 코드 라인**: ~1,600 라인 (HTML/CSS/JavaScript)
- **컴포넌트 수**: 8개 (기록폼, 목록, 3가지 시각화 등)
- **시각화 차트**: D3.js 기반 3종 (사인파, 막대, 히트맵)
- **필터 옵션**: 6개 (감정/장소/신체/날짜/검색/초기화)
- **데이터 형식**: JSON (로컬 스토리지) + JSON/CSV (내보내기)

## 개발 히스토리

- **Phase 1 (MVP)**: 기본 기록 및 사인파 시각화
- **Phase 2 (시각화)**: 장소/신체 시각화, 사용자 정의 카테고리
- **Phase 3 (고급 기능)**: 필터링, 검색, 데이터 내보내기
