# 감정 기록 앱 (Emotion Tracking App)

감정을 시간, 장소, 신체와 함께 기록하고 다차원으로 시각화하는 웹 애플리케이션입니다.

## 기능

### Phase 1 MVP (완료)
- ✅ 감정 기록 기능 (복수 감정 선택, 강도 설정)
- ✅ 신체 감각 기록 (2D 신체 맵)
- ✅ 시간 및 장소 기록
- ✅ 로컬 스토리지 데이터 저장
- ✅ 기록 목록 뷰 (수정/삭제)
- ✅ 사인파 시각화 (하루/주/월/년 스케일)

### 다음 단계
- 🔄 장소 시각화 (지도, 카테고리별)
- 🔄 신체 히트맵
- 🔄 고급 필터링 및 검색
- 🔄 숨은 카테고리 시스템 (의식 탐구 도구)

## 사용 방법

1. `index.html` 파일을 브라우저에서 열기
2. "기록하기" 탭에서 감정 기록
3. "기록 목록"에서 저장된 기록 확인
4. "시각화"에서 시간에 따른 감정 패턴 확인

## 기술 스택

- React 18 (CDN)
- D3.js v7 (데이터 시각화)
- LocalStorage (데이터 저장)
- Vanilla CSS (스타일링)

## 핵심 개념

이 앱은 두 가지 방식으로 사용할 수 있습니다:

1. **일반 사용자**: 감정 패턴을 추적하고 자기 이해를 증진
2. **수행자**: 특정 키워드 사용 시 의식 탐구 도구로 확장

숨은 기능은 사용자가 자연스럽게 발견하도록 설계되었습니다.
